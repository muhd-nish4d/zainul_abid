# Zainul Abid Portfolio

A handcrafted, high-end portfolio experience for graphic designer SAINUL ABID, built with React 19, Vite 8, TypeScript, Tailwind CSS, Framer Motion, GSAP, and Lenis.

## Features
- Multi-page portfolio experience with handcrafted editorial styling
- Responsive layout for mobile, tablet, and desktop
- Custom content structure for easy editing
- Placeholder assets and frames for future image replacement
- SEO basics with robots.txt and sitemap.xml

## Installation
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Deployment
Deploy the generated dist folder to any modern static host such as Vercel, Netlify, or GitHub Pages.

## Customization Guide
- Update content in src/data/content.ts
- Replace placeholder frames in the page components with actual images
- Adjust colors and typography in src/index.css and tailwind.config.js
